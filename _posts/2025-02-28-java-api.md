### 1. Arrays.sort()

- **用途：** 对数组进行排序。  
- **特点：**  
  - 支持对基本数据类型和对象数组排序。  
- **示例：**

  ```java
  int[] arr = {3, 1, 2};
  Arrays.sort(arr);  // 对基本类型数组进行排序
  
  ```


---

### 2. Collections.sort()

- **用途：** 对 `List` 集合进行排序。  
- **特点：**  
  - 适用于对象集合。  
- **示例：**

  ```java
  List<Integer> list = new ArrayList<>(Arrays.asList(3, 1, 2));
  Collections.sort(list);  // 使用自然顺序排序
  
  ```

---

### 3. List.sort() 方法

- **用途：** 从 Java 8 开始，`List` 接口新增了 `sort` 默认方法，可以直接对 `List` 排序。  
- **特点：**  
  - 功能与 `Collections.sort()` 类似，但更加简洁。  
- **示例：**

  ```java
  List<Integer> list = new ArrayList<>(Arrays.asList(3, 1, 2));
  list.sort(null);  // 使用自然顺序排序
  
  // 使用自定义排序规则
  list.sort((a, b) -> a - b);
  ```

## ThreadLocal

**ThreadLocal 的作用：**

- **线程局部存储**：  
  为每个线程提供独立的变量副本，不同线程间互不干扰。

- **数据隔离**：  
  避免多线程共享变量时的同步问题，每个线程读写自己专属的数据，适用于存储用户上下文、事务信息等。

- **简化编程**：  
  通过 ThreadLocal，可以在不使用同步机制的前提下实现线程安全的数据访问。

---

**示例代码：**

```java
public class ThreadLocalDemo {
    // 定义一个 ThreadLocal 变量，存储每个线程的独立数据
    private static ThreadLocal<Integer> threadLocal = new ThreadLocal<>();

    public static void main(String[] args) {
        Thread threadA = new Thread(() -> {
            threadLocal.set(100);  // 为当前线程设置值
            System.out.println("Thread A value: " + threadLocal.get());
        });

        Thread threadB = new Thread(() -> {
            threadLocal.set(200);  // 为当前线程设置不同的值
            System.out.println("Thread B value: " + threadLocal.get());
        });

        threadA.start();
        threadB.start();
    }
}
```

**讲解要点：**

- 每个线程通过 `threadLocal.set()` 设置自己的值，互不干扰。  
- 调用 `threadLocal.get()` 时，每个线程获得的是自己设置的值，而不会受到其他线程影响。  
- 这种机制非常适合用于需要线程隔离数据的场景，简化了并发编程的复杂性。
